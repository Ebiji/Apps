# Suno Mastering Studio

SUNO で生成した **MP3 / WAV** を、聴く環境に合わせてブラウザ内でマスタリングするアプリです。
ビルド不要・サーバー不要・音声は外部送信されません（Web Audio API）。

## 使い方
```
cd App && python3 -m http.server 8000   # → http://localhost:8000
```
（`file://` ではなく HTTP で開いてください。静的ホスティング / GitHub Pages でも動作します）

1. MP3 / WAV を選択（ドロップ可）
2. **条件を入力**: 視聴条件プリセット、言葉の指示（「こもっているので明るく」「bass +3dB」「-12LUFSで」など）、詳細スライダー
3. **手動で調整したい場合**: 「手動プレビュー」を選んで再生し、スライダーを動かすとその場で音が変わります（音量は元の音に揃うので、音色の違いだけを比較できます）
4. **「マスタリング開始」** を押すと、曲全体を自動でマスタリング（目標ラウドネスの自動測定込み）
5. 「元の音 / マスタリング済み」で聴き比べ。周波数バランスの前後比較グラフも表示されます。条件を変えたら再度マスタリング
6. **「保存」** で任意のタイミングに WAV 16/24bit または MP3 をダウンロード

## 処理チェーン
ローカット → 6バンドEQ → 並列エンハンサー（低音倍音 / 高域エキサイター / サチュレーション）
→ M/S ステレオ幅 → **エフェクト（オートパン / フィルター / フェイザー）** → コンプ → 自動ラウドネス（BS.1770 K特性、目標LUFS）→ リミッター → ピーククリップ

ライブ再生と書き出しで同一グラフ（`js/chain.js`）を使うので、聴いた音がそのまま保存されます。

## エフェクト（既定はすべてオフ）
- **オートパン**: 左右の音量を逆位相で揺らす（深さ / 速さ）
- **フィルター**: ローパス・ハイパス・バンドパス、カットオフ / レゾナンス / 効き具合 / LFOスイープ（幅・速さ）。バンドパス＋スイープで「ワウ」
- **フェイザー**: オールパス6段をLFOで動かす（量 / 速さ / 深さ / フィードバック）
- 言葉でも指示できます: 「フェイザーをかけて」「オートパンを少し」「ローパスフィルターで1000Hzに」「ワウ」「フィルタースイープ」

## 言語指示
`js/nlp.js` のルールベース解釈（オフライン）。日本語/英語のキーワード・程度（少し/かなり）・方向（上げる/下げる/〜すぎ）・数値（dB, LUFS）に対応。
語彙は `ADJECTIVES` / `DIRECTIONAL` に追記するだけで増やせます。


## 注意
- **claude.ai 上の公開ページ**では標準のダウンロードが使えず、プラットフォームの保存機能（wav/mp3 は許可形式外）を使うため、**ZIPに入れて保存**します。ローカルで開けば WAV/MP3 を直接保存でき、Chrome/Edge では保存先も選べます。
- MP3 書き出しは lamejs を CDN から遅延ロードします（ネット接続が必要）。
- ラウドネスは BS.1770 の K特性・ゲーティングによる実装で、True Peak ではなくサンプルピーク＋4xオーバーサンプリングのクリッパーで上限を守ります。
